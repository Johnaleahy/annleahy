# Ann Leahy’s website

Live site: https://johnaleahy.github.io/annleahy/

## Pages

- `index.html` opens the coaching homepage and preserves query strings and section links.
- `ann_leahy_menu.html` contains the coaching homepage, styles, and navigation.
- `book.html` contains the consultation form.

## Publishing

GitHub Pages publishes the root of the `main` branch. Push a commit to `main`, then check **Settings → Pages** or the Pages deployment in GitHub Actions. No build step is needed. Keep image filenames and references identical, including capitalization.
